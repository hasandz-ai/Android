Google Sheets Backend Connection

Masukkan URL Web App dari Google Apps Script (`Code.gs`) yang telah di-deploy untuk mengaktifkan fitur Push/Pull data otomatis.

URL ini didapat setelah melakukan Deploy as Web App di Google Sheets Apps Script.
Status Sinkronisasi: Belum Pernah Sync
Penyimpanan aktif: Local Storage (PWA Offline-First)

Panduan Setup Google Sheets Backend

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka menu Extensions > Apps Script.
  3. Salin seluruh kode dari file Code.gs ke dalam editor Apps Script.
  4. Klik tombol Deploy > New deployment.
  5. Pilih type Web app, atur access ke "Anyone".
  6. Salin Web App URL yang dihasilkan dan tempelkan pada kolom di samping.
